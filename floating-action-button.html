Floating Action Button

A floating action button (FAB) with expandable action menu. Provides quick access to common actions from anywhere on the page.

LWC JavaScript

import { LightningElement, track } from 'lwc';

export default class SfFloatingActionButton extends LightningElement {
    @track isExpanded = false;
    
    @track actions = [
        { 
            id: '1', 
            label: 'New Contact', 
            iconUrl: '/assets/icons/utility-sprite/svg/symbols.svg#user' 
        },
        { 
            id: '2', 
            label: 'New Account', 
            iconUrl: '/assets/icons/utility-sprite/svg/symbols.svg#account' 
        },
        { 
            id: '3', 
            label: 'New Opportunity', 
            iconUrl: '/assets/icons/utility-sprite/svg/symbols.svg#opportunity' 
        },
        { 
            id: '4', 
            label: 'New Case', 
            iconUrl: '/assets/icons/utility-sprite/svg/symbols.svg#case' 
        }
    ];

    toggleFab() {
        this.isExpanded = !this.isExpanded;
    }

    handleAction(event) {
        const actionId = event.currentTarget.dataset.id;
        const action = this.actions.find(a => a.id === actionId);
        
        this.dispatchEvent(new CustomEvent('actionclick', {
            detail: { action: action }
        }));
        
        this.isExpanded = false;
    }
}

Usage Notes

  • Custom floating action button not in standard Salesforce documentation
  • Expands to show action menu items
  • Uses SLDS icons for action items
  • Click outside to close the menu
  • Perfect for quick create actions on any page
  • Can be positioned anywhere on the page
