Search with Filters

A search input component with dynamic filter chips. Users can search and apply multiple filters with the ability to remove individual filters.

import { LightningElement, track } from 'lwc';

export default class SfSearchFilters extends LightningElement {
    @track searchTerm = '';
    @track placeholder = 'Search accounts, contacts, or opportunities...';
    
    @track filters = [
        { id: '1', key: 'Type', value: 'Customer', label: 'Type: Customer' },
        { id: '2', key: 'Status', value: 'Active', label: 'Status: Active' },
        { id: '3', key: 'Industry', value: 'Technology', label: 'Industry: Technology' }
    ];

    handleSearch(event) {
        this.searchTerm = event.target.value;
        // Emit search event with filters
        this.dispatchEvent(new CustomEvent('search', {
            detail: { 
                term: this.searchTerm, 
                filters: this.filters 
            }
        }));
    }

    removeFilter(event) {
        const filterId = event.currentTarget.dataset.id;
        this.filters = this.filters.filter(f => f.id !== filterId);
        
        // Emit updated filters
        this.dispatchEvent(new CustomEvent('filterchange', {
            detail: { filters: this.filters }
        }));
    }

    showFilterModal() {
        // Emit event to show filter selection modal
        this.dispatchEvent(new CustomEvent('showfiltermodal'));
    }
}

Usage Notes

  • Custom search component with dynamic filters not in Salesforce docs
  • Uses SLDS Input and Pill components for styling
  • Filter chips are removable with X button
  • Search and filter events can be used for data fetching
  • Add Filter button can trigger a modal for filter selection
  • Perfect for list views and global search implementations
