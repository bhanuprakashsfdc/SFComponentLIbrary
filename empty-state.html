Empty State

A component to display when there's no data available. Provides a visual cue and action to help users proceed.

Preview

No Records Found

There are no records to display. Try adjusting your search or filter criteria to find what you're looking for.

LWC JavaScript

JavaScript 
import { LightningElement, api } from 'lwc';

export default class SfEmptyState extends LightningElement {
    @api title = 'No Records Found';
    @api description = 'There are no records to display.';
    @api primaryActionLabel = 'Create New Record';
    @api secondaryActionLabel = 'Clear Filters';
    @api iconName = 'folder';

    handlePrimaryAction() {
        this.dispatchEvent(new CustomEvent('primaryaction'));
    }

    handleSecondaryAction() {
        this.dispatchEvent(new CustomEvent('secondaryaction'));
    }
}

Usage Notes

  • Custom empty state component with improved styling
  • Use when no data is available in lists, tables, or searches
  • Configurable title, description, and action buttons
  • Dispatches events for primary and secondary actions
  • Provides better UX than showing a blank page
