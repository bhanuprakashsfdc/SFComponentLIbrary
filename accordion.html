Core Component

Accordion

A component that allows users to toggle the visibility of sections of content. Built with SLDS patterns and fully compatible with LWC.

Preview

Salesforce is a customer relationship management (CRM) platform that helps businesses manage customer data, track interactions, and automate sales processes. It provides a suite of tools for marketing, sales, customer service, and analytics.

Lightning Web Components (LWC) are a Salesforce programming model for building enterprise-scale applications. They use standard HTML, CSS, and JavaScript, combined with powerful Salesforce APIs and platform features.

You can deploy Lightning Web Components to Salesforce using Salesforce CLI, VS Code with Salesforce Extensions, or by packaging them in a managed package.

LWC HTML Template

HTML 
<template>
    <div class="slds-accordion">
        <template for:each={sections} for:item="section">
            <div class="slds-accordion__section" key={section.id} class:slds-is-open={section.isOpen}>
                <button class="slds-accordion__summary-action" 
                        aria-controls={section.contentId} 
                        aria-expanded={section.isOpen}
                        onclick={toggleSection}>
                    <svg class="slds-accordion__summary-action-icon slds-icon slds-icon_x-small slds-icon-text-default" aria-hidden="true">
                        <use xlink:href="/assets/icons/utility-sprite/svg/symbols.svg#switch"></use>
                    </svg>
                    <span class="slds-accordion__summary-heading">{section.title}</span>
                </button>
                <div class="slds-accordion__content" id={section.contentId}>
                    <p>{section.content}</p>
                </div>
            </div>
        </template>
    </div>
</template>

LWC JavaScript

JavaScript 
import { LightningElement, track } from 'lwc';

export default class SfAccordion extends LightningElement {
    @track sections = [
        {
            id: 'section-1',
            title: 'What is Salesforce?',
            contentId: 'accordion-content-1',
            content: 'Salesforce is a CRM platform that helps businesses manage customer data, track interactions, and automate sales processes.',
            isOpen: true
        },
        {
            id: 'section-2',
            title: 'What are Lightning Web Components?',
            contentId: 'accordion-content-2',
            content: 'Lightning Web Components (LWC) are a Salesforce programming model for building enterprise-scale applications.',
            isOpen: false
        },
        {
            id: 'section-3',
            title: 'How do I deploy components to Salesforce?',
            contentId: 'accordion-content-3',
            content: 'You can deploy Lightning Web Components to Salesforce using Salesforce CLI, VS Code with Salesforce Extensions.',
            isOpen: false
        }
    ];

    toggleSection(event) {
        const sectionId = event.currentTarget.closest('.slds-accordion__section').dataset.id;
        this.sections = this.sections.map(section => ({
            ...section,
            isOpen: section.id === sectionId ? !section.isOpen : section.isOpen
        }));
    }
}

Usage Notes

  • Uses Salesforce Lightning Design System (SLDS) accordion patterns
  • Compatible with Lightning Web Components (LWC)
  • Uses @track decorator for reactive property updates
  • Implements toggle logic with map() for immutability
  • Uses for:each directive for rendering sections
  • Includes proper ARIA attributes for accessibility
