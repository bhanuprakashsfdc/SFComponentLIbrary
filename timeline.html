Usage Notes

  • Custom component not available in standard Salesforce documentation
  • Uses only SLDS CSS classes for styling (no custom CSS required)
  • Supports three states: completed, current (with pulse animation), and pending
  • Fully LWC compatible with @track decorator
  • Uses for:each directive for rendering timeline items
  • Responsive design that works on all screen sizes
